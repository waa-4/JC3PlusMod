# JC3 Plus

> JC3 Plus is unofficial and is not made or supported by Avalanche Studios or Square Enix.

JC3 Plus is a free expansion and sandbox mod for Just Cause 3.

The goal is to give the game more things to do, more ways to mess around, and more reasons to come back after finishing the main game.

This project is still very early in development, so a lot of the planned features may change depending on what is possible to mod.

## Planned Features

- Sandbox mode
- Object spawning
- NPC spawning
- Vehicle spawning
- Player stat editing
- Physics editing
- Freecam
- Restored unused or scrapped weapons and vehicles
- Custom weapon creator
- Custom projectile settings
- Map designer
- NPC creator
- New secrets and joke features
- More gameplay settings
- Random events
- More postgame content
- Other experiments

Some features will probably take much longer than others.

## Current Status

JC3 Plus is currently in very early development.

The first goals are:

1. Get basic mod loading working
2. Edit weapon stats
3. Edit vehicle stats
4. Find and test unused content
5. Start experimenting with spawning and sandbox tools

The first builds will probably be small and experimental.
